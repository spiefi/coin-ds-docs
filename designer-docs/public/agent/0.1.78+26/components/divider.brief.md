# Divider (brief)

> Coin agent pack 0.1.78+26 · undocumented · full entry: `components/divider.md` (sources, all facts, flags)

Divider component that renders a horizontal or vertical separator line. This component is used to visually separate content sections. (Package docs; Coin has no designer guide for Divider.)

**Example:** A horizontal separator between two sections.

```tsx
<Divider direction="horizontal" modes={{ 'Color Mode': 'Light' }} />
```

**Props:** `direction` (vertical | horizontal), `modes`, `style`, `accessibilityLabel`. (* required)

**Modes it reads:** Color Mode, context 10, Profile Card Appearance.
